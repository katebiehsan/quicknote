# Quicknote

Offline-Notizen für den Home-Bildschirm. Notizen werden zuerst auf dem Gerät gespeichert und als Issue an das private Repo `quicknote-inbox` geschickt. Claude überträgt sie stündlich (8–23 Uhr) in Second Brain und schreibt `mirror.json` mit allen Notizen zurück, die die App für Lesen und Suchen offline lädt.

Hier liegt nur der App-Code, keine Notizen.
